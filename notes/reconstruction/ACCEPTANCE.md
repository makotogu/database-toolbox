# V2 分阶段实施与验收

日期：2026-09-16。对应 [重构方案](README.md)。

**以下保留原设计的验收标准，不代表每个条目均已通过。** V2 已实施；本次实际测试、环境矩阵、设计取舍与未验证项目统一见 [DELIVERY.md](DELIVERY.md)。旧版基线记录见 [BASELINE.md](BASELINE.md)。

## 1. 总体验收原则

- 通过 = 有对应代码、可重复命令/操作、实际输出和环境记录。mock 驱动测试只证明执行算法，不证明真实厂商驱动兼容。
- `未验证`、`阻塞`、`不支持` 分开记录；重点目标库缺少真实验证时，不标记全量交付通过。
- UI 功能需要浏览器操作并检查渲染结果，HTTP 200 或接口测试不能代替交互验收。
- M1/M2 的阶段包是中间成果。存过、EXPLAIN、代码块、多语句脚本全部在最终 V2 门槛内。
- 每阶段复用有效的既有测试结果；只有新增行为、改动或失败才扩大重测。

### 可重复的脚本样例

以下为原设计样例。实际集成验证使用 `scripts/smoke-v2.py` 的临时测试对象，执行情况见交付记录。

MySQL 过程体、参数与多个结果集（A31–A33）：

```sql
DELIMITER $$
CREATE PROCEDURE toolbox_probe(IN p_in INT, INOUT p_count INT, OUT p_out INT)
BEGIN
  SET p_count = p_count + p_in;
  SET p_out = p_in * 2;
  SELECT p_in AS id, p_out AS id;
  SELECT 'body;still one statement' AS message;
END$$
DELIMITER ;
SET @count = 10;
CALL toolbox_probe(3, @count, @out);
SELECT @count AS counter, @out AS doubled;
DROP PROCEDURE toolbox_probe;
```

期望：创建过程是一个单元；CALL 的两组结果都能看到；最后查询为 13、6。另通过调用向导以 `CallableStatement` 验证 INOUT/OUT，不能只凭会话变量调用就认定 OUT 参数已实现。

PostgreSQL 代码块与同连接脚本（A34、A37）：

```sql
CREATE TEMP TABLE toolbox_probe (n integer);
DO $body$
DECLARE
  v integer := 7;
BEGIN
  INSERT INTO toolbox_probe VALUES (v);
  RAISE NOTICE 'inside;block';
END;
$body$;
SELECT n, 'not;a;delimiter' AS note FROM toolbox_probe;
DROP TABLE toolbox_probe;
```

期望：四个执行单元，查询返回 n=7；分号字符串不影响拆分；临时表可见证明脚本使用同一会话。GaussDB 样例在 A03 固定实际兼容模式后编写并留档，不能用 PostgreSQL 的结果替代其验收。

词法测试至少覆盖：单/双引号、反引号、转义引号、MySQL SQL_MODE 差异、行/块注释、支持方言的嵌套注释、dollar quote、DECLARE、嵌套 BEGIN/END、IF/CASE/LOOP、DELIMITER、独占行 `/`、空脚本、末尾未闭合结构。每条测试断言“发送了哪些完整单元与源范围”，不只断言数量。

最终示范路径必须一次连贯完成：

```text
独立 JAR 启动 → 导入外部 JDBC 驱动 → 连接数据库
→ 浏览表结构/内容 → 查询结果 → 调用存过并查看 OUT/多结果
→ 执行完整代码块与脚本 → 查看 EXPLAIN
→ 验证回滚和取消 → 退出/重启 → 连接与驱动配置仍可用
```

## 7. 实施期验证安排

| 验证层 | 重点 | 能证明什么 |
| --- | --- | --- |
| Java 单元测试 | 词法边界、ResultReader 多结果、类型编码、驱动错误和配置迁移 | 工具自身规则与资源释放逻辑 |
| 受控 JDBC 假驱动 | 同名类版本隔离、混合结果、忽略取消、异常链 | 难以稳定复现的驱动边界；不证明厂商兼容 |
| 外置 H2 驱动集成 | 驱动导入、连接、表结构、基础查询、事务 | 无外部服务的真实 JDBC 通路；不替代存过/方言测试 |
| MySQL/PostgreSQL/GaussDB 集成 | 真实语法、参数模式、执行计划、脚本及取消 | 指定数据库/驱动组合的兼容性 |
| 浏览器验证 | 完整用户路径、长表格、错误状态、多标签、离线加载 | 实际交互与渲染可用 |
| 独立 JAR 冒烟 | 空工作目录、Java 8、资源/驱动/配置、重启 | 最终发行形式确实可运行 |

开发期命令沿用现有 Java 8 入口：

```bash
JAVA_HOME=$(/usr/libexec/java_home -v 1.8) mvn test
JAVA_HOME=$(/usr/libexec/java_home -v 1.8) mvn package
```

前端保持无构建流水线；修改的 ES module 做语法检查，并在浏览器验证。需要环境的集成测试独立标记；未配置 GaussDB 时可以跳过日常构建，但发布记录必须显示“未验证”，不能把跳过计为通过。

每个用例记录：`ID / commit+工作区摘要 / Java+OS / DB+驱动 / 操作或命令 / 实际结果 / 证据位置 / 通过或失败或未验证`。
