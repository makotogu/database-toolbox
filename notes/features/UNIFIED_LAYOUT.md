# 单层顶部栏与拖拽布局

品牌、菜单、连接选择和常用操作合并为一条 54px 顶部栏。窄屏保留四个菜单，连接选择仍可在标签上下文中使用。

本轮按用户选择实现面板调大小与标签排序，不包含浮动窗口或自由停靠。

- 导航右侧和编辑器/结果之间提供可见分隔线，可用鼠标或指针拖动、方向键微调、Home/End 调到边界；双击恢复单项默认，视图菜单可重置全部尺寸。
- 调整尺寸后，切换标签、执行状态重绘或窗口大小改变会保留偏好并按可用空间约束。窗口缩至窄屏后收起导航，返回桌面恢复先前可见状态。
- 浏览器只存储数值宽度和比例；不新增 SQL、连接、标签或结果存储。异常或不可用存储不影响内存中的布局操作。
- 标签拖动和菜单向左/向右移动只改变显示与关闭顺序，保留活动标签、编辑器 DOM/选区、SQL、结果和会话。内部拖放使用专用类型并阻止无效落点的默认操作，不能向编辑器插入文本。
- 保持单 JAR、Java 8、原生前端及每标签独立会话；未修改后端或数据库适配能力。
